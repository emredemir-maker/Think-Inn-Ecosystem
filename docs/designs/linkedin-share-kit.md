# CEO Plan: LinkedIn Paylaşım Kiti (native içerik üretici)

## Problem / Outcome
Think-Inn'deki araştırma/projeleri LinkedIn'de **insan sesiyle, gerçek veriye dayalı** içerikle tanıtıp ilgili
think-Inn sayfasına nitelikli trafik çekmek. "İnsan yazmış gibi" = mimari değil, kalite/ton problemi:
her taslak gerçek entity verisine + brand voice'a (DESIGN.md §15) + birinci-tekil anlatıya + zorunlu insan-edit turuna dayanır.

## Premise Challenge — kilit ters köşe
**LinkedIn algoritması dış-link içeren gönderileri baskılar.** "Makaleyi sitede barındır + linki paylaş" stratejisi
erişimi düşürür. Doğru hamle: **LinkedIn-native uzun-form içerik** üret; derin link gönderinin GÖVDESİNE değil
**ilk yoruma** konur. Bu yüzden asıl ürün = native içerik üretici; derin link + OG ikincildir (link verildiğinde güzel görünsün diye).

## Seçilen Yaklaşım — Approach A: Paylaşım Kiti
1. Entity başına **kanonik public derin link** route'ları: `/r/:id` (araştırma), `/p/:id` (proje/fikir) → public read-mode detayını açar.
2. O route'lara **OG meta** (per-entity og:title/description/image). og:image = mevcut `cover-image.ts`.
3. Detayda (admin) **"LinkedIn için içerik üret"**: Gemini, gerçek entity verisi + brand voice ile **çoklu açıda**
   (kurucu hikâyesi / problem→çözüm / araştırmanın arkası) insan-sesi uzun-form üretir → kullanıcı düzenler → kopyalar.
4. Paylaşım: derin linki kopyala + "LinkedIn'de Paylaş" intent + linki ilk-yoruma koyma akışı.

## Accepted Scope (bu plana dahil)
- Kanonik public derin link route'ları (`/r/:id`, `/p/:id`) + public-safe entity projeksiyonu
- Per-route OG meta: **Vercel serverless/edge function** (catch-all rewrite'tan ÖNCE) crawler'a per-entity OG'li HTML döner; insan SPA'ya hidrate (link markalı domainde kalır)
- `POST /:type/:id/generate-linkedin` — çoklu açı, insan-sesi uzun-form + ilk-yorum metni + hook varyantları + hashtag
- "İnsanlaştır" ikinci-pass + ton kaydırıcı (kişisel ↔ analitik)
- Üretim modalı (açı seç, hook seç, ton ayarı, kopyala, ilk-yorum kopyala) + "LinkedIn'de Paylaş" + derin link kopyala

## RESOLVED DECISIONS
1. **OG meta yöntemi → Vercel serverless/edge function (markalı domain).** `/r/:id`, `/p/:id` için catch-all rewrite'tan
   ÖNCE çalışan function; crawler'a (ve herkese) per-entity OG'li HTML döner, insan tarafı SPA'ya hidrate olur. Link app domaininde kalır.
2. **Public-data kapısı → "paylaşıma açık" işareti + alan allowlist.** Admin entity'yi paylaşıma açar; public endpoint yalnız allowlist alanları döner.

## Implementation Notes (eng review girdisi — spec-review 6/10 bulguları işlendi)
- **Deep-link routing (net-new iş):** App **wouter** kullanıyor; `/r/:id`,`/p/:id` route'ları YOK, detay **event-bus** ile açılıyor.
  Yeni public read-mode route bileşenleri id'den entity'yi fetch eder, CardDetailView'i public+read modda **doğrudan** render eder (event-bus'tan bağımsız). Bu meta-only değil, gerçek routing işi.
- **OG tag seti (tam):** `og:title`, `og:description`, `og:image` (mutlak Fly kapak URL'i, 1200×627), `og:url`, `og:type=article`, `og:locale=tr_TR`, `twitter:card=summary_large_image`. Kapak/özet yoksa **marka fallback** görseli + jenerik açıklama.
- **OG image:** kaynak = Fly kapak endpoint'i (Neon'da base64; `research.ts` cover route). Boyut sınırı kontrol; kapağı olmayan entity için brand fallback PNG. LinkedIn OG cache'i agresif → **Post Inspector** ile re-scrape notu.
- **Public alan allowlist (kesin):** research → {title, summary, tags, coverUrl}; idea/project → {title, description, category, usageFlow(roadmap), genel skor özeti, coverUrl}. **HARİÇ:** financial, risk notları, projectTeam, ham architecturalAnalysis metni, admin alanları.
- **`generate-linkedin` endpoint:** varsayılan dil **TR** (çoklu-dil deferred); max uzunluk + token sınırı; rate-limit/cost guard; Gemini hata yolları (timeout/boş/malformed/refusal) → kullanıcıya net mesaj; **otomatik yayınlama YOK**.
- **"İnsan sesi" → testlenebilir rubrik + ZORUNLU insan-edit kapısı:** çıktı "umut" değil; kontrol listesi (klişe-yok, birinci-tekil, ≥2 somut gerçek-veri atıfı, tek hashtag bloğu) + üretilen metin **her zaman** kullanıcı edit/onayından geçer (auto-publish yok).
- **Modal durumları:** loading / boş / hata / başarı + üretim sırasında iptal.
